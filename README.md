# The Rig's SO

System operations, native file housekeeping automation, and drive organization utilities.

## Features
- **Rig Housekeeper**: High-concurrency native in-process file archiving engine with GUI controls and quarantine protection for OS, DAW, and game assets.
- **Drive Organizer**: CLI & GUI tools for scanning storage roots, classifying media and documents, and moving files with collision-safe renaming.
- **Housekeeping App**: Desktop GUI interface for reviewing inventory, protected folders, and executing archive plans.
